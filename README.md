# 🎓 Student Performance Predictor

A Machine Learning web app that predicts a student's exam score based on study habits.

## 🔧 Tech Stack
- Python, Scikit-learn, Streamlit, Pandas

## 📊 Features
- Predicts score based on study hours, attendance, previous score & sleep hours
- Interactive sliders for input
- Visual feedback based on performance level

## 🚀 How to Run
pip install -r requirements.txt
python -m streamlit run app.py

## 📁 Project Structure
- `dataset.csv` - Training data
- `train_model.py` - Model training script
- `app.py` - Streamlit web app
- `model.pkl` - Saved ML model
